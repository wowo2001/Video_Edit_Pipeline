# main 整集母版预处理

`tasks.json` 一批只放同一部电视剧的不同集数。

每个任务用 `episode` 正整数指定集数，例如 `{"title":"大明王朝1566","episode":1,"urls":"https://youtu.be/..."}`。不再用任务的 `subtitle` 表示集数。工作目录固定为 `work/剧名/第001集`，与任务排列顺序无关；旧项目原目录保留。

每集 `metadata.json` 集中管理剧名、集数、剪辑脚本（`script`）、标题、副标题、AI 原始副标题、弹幕、字体/位置、速度、背景音乐、GIF（`render`），以及素材路径（`source`、`assets`）和入库结果（`database`）。`media.json` 只作运行素材记录，`main_postprocess.json` 保留识别缓存。修改标题、副标题、弹幕或布局后可用 `render_main.py` 重渲染；编辑旁白或选段需要重做配音、剪辑和拼接。`script.json` 是规划生成及时间轴转换的兼容文件，后续 main 剪辑读取 metadata 的脚本。

新副标题来自字幕校正模型的 `title`，保存在 `render.generated_subtitle` 并默认用于 `render.subtitle`；可以直接编辑 `render.subtitle`。旧版没有保存的 AI 标题不能恢复，旧项目迁移时保留原显示副标题。重渲染优先使用 metadata；明确传入 `--profile` 时使用该配置的文字布局。

数据库先执行 `database/migrate_add_episode.sql`，在故事、场景、对白表中增加可空的 `episode`。写入前查剧名与集数，已存在就跳过整集入库；其余 INSERT/upsert、写入顺序及逐条提交方式不变。不同集不需要按数据库 ID 顺序完成，查对白使用 `ORDER BY episode, start_time, id`。没有新增锁或唯一约束；已有部分记录的集也会跳过，应单独检查其完整性。

## 使用

- 双击 `run_main.bat`：首次先下载第一集原始素材，打开选区页面；保存后整批自动运行。
- 双击 `configure_main.bat`：单独修改选区并保存，不启动制作或上传。
- 已有该剧配置时，`run_main.bat` 自动复用，不再询问。
- 页面关闭不会自动跳过；点击取消或终端 Ctrl+C 可结束等待。

选区工具支持 16 张缩略图、时间轴、逐帧定位、多个模糊区域、裁剪框，以及当前位置三秒实际编码预览。
点击右侧区域可移动或拖右下角调整大小；点击“框选模糊区域”可继续添加。没有模糊区域表示明确跳过。
新增、移动、缩放、删除、清空、裁剪及画质调整均支持撤销和重做：按钮或 Ctrl+Z / Ctrl+Y（也支持 Ctrl+Shift+Z）。Esc 取消当前拖动。刷新本页可恢复未保存选区和撤销记录。
“抓手 / 移动框”模式可直接点住任意模糊框或绿色裁剪框移动，画完框会自动切换到抓手；选中框右下角可调整大小。

绿色框内的画面保留；默认中央 4:3，可改完整画面或自定义。选区为相对坐标，跨分辨率复用。不同宽高比的集数会报告失败并继续下一集。
旁边的 9:16 实时预览显示最终构图：默认画面自动铺满 1080 宽，上下留黑放标题；选择“竖屏全屏（9:16）”则会裁去更多左右内容。实际三秒视频预览与 main 使用同一套竖屏适配规则。

## 解说规划提示词

- `prompts/script_input.py`：整集输入结构及含义；场景按时间排列，每条字幕保留全局索引。推荐场景仅作候选标记，不过滤掉其余场景。未被场景覆盖的字幕保留为背景材料，不静默丢弃。
- `prompts/editing_rules.py`：选材、节奏、悬念、原声与解说分工、开场及收束。主要创作调整改这里。
- `prompts/script_schema.py`：输出保留 `hook`、`clips`、`narrative.content`、`clip` 和正文 `place`，正文增加 `type` 与 `purpose`。
- `prompts/generate_script.py`：组合上述三部分，每次仍只调用一次模型。移除了未使用的推荐场景字幕文件生成步骤和重复的任务说明文件。

策略要求看到全局后围绕一个核心问题选讲，保留必要铺垫，避免重复原声或提前说破原声即将揭示的内容，逐步兑现悬念并在结尾回应开场。带原声段连续保留所选完整对白及句间空隙。

正文最多 10 段；解说不限定句数，以讲清当前段落为准。每段原声最好控制在 5 个完整语义句以内，是节奏建议而非硬上限，完整性优先。所选原声必须从自然开头到完整表达结束；完整句跨多条字幕时需连续选全，不能把字幕条数当句数，也不能为了凑句数删掉必要回答或截半句。

规划输入只提供场景摘要及带全局索引的字幕文本，不附加时长或时间戳，不以秒数限制原声。

## 成片字幕

“字幕定位 / 放大”可放大竖屏预览。拖动蓝色字幕框设置位置，拉右下角调整总宽度，也可输入 X/Y、宽度、字号和最多行数。所有数值以 1080×1920 成片像素为准。

字幕使用得意黑，按实际字宽折行。一个字幕时间段的文字超过最多行数时，会在该时间段内按文字长度分屏展示，保留全部文字。框选位置、宽度和行数应用到 main 的正式字幕；生成的 ASS 布局字幕保存在每集 `final_render.ass`，原始 SRT 不改。

示例文字只用于 UI 与三秒视频预览。正式字幕仍来自成片识别与修正。字幕布局存入剧集公共配置的 `caption_layout`；只改字幕布局不会使整集母版缓存失效，也不会把这些字幕烧进上传 S3 的整集母版。

## 文件与编码

- 原始下载缓存：`work/source_download_cache/`，下载只合并容器，不重新编码，保留用于重新选区。
- 按剧名保存的公共配置：`work/preprocess_profiles/`。
- 每集 `video.mp4`：裁剪、模糊、缩放后的一整集母版，原声保留。
- 裁剪、模糊、缩放、CRF 压缩合并为一次 H.264/medium 编码，默认 CRF 20，最高 720p，不主动放大。
- 多源视频统一规格后采用 stream copy 拼接，不再编码。字幕识别使用拼接母版本身的音轨。
- 编码结果按原片身份和配置指纹缓存；更改配置会重新生成母版。
- S3：`videos/masters/v1/<指纹>/source.mp4` 及同目录 `preprocess.json`，记录选区、参数和输出尺寸。
- main 成片阶段不再额外模糊或固定裁中央 4:3，按母版比例铺满竖屏宽度；上下不足补黑，超出则居中裁去。
- 结果报告：`work/main_batch_result.json`。失败集数记录后继续，最终返回非零退出码。

本次先接入 main；search 仍沿用旧流程，尚未接入母版标记及省略重复处理。

## main 成片合并渲染

拼接完成之后，main 直接从拼接视频提取 1.2 倍速音频进行识别，不先渲染竖屏或加速视频。识别音频始终不含背景音乐。

字幕识别及 AI 修正完成后，一条 FFmpeg 滤镜链统一完成视频加速、竖屏适配、字幕、标题/副标题、弹幕、点赞 GIF 与可选背景音乐。视频只编码一次，结果为 `final_video.mp4`，原有五个后处理 MP4 不再生成。GIF 和背景音乐按正常速度播放；字幕与弹幕使用加速后的时间轴。

main 正文支持两种剪辑类型：`narration_only` 用连续剧情画面承载旁白，只使用配音音轨，不追加原声；`with_dialogue` 先旁白、后完整原声。`purpose` 说明每段的叙事作用，不参与配音；两种类型继续共用 `clip` 全局字幕索引，纯旁白按 TTS 长度取画面，限制在对应场景内，场景太短时明确报错。hook 仍为原声后接解说。旧脚本未写 `type` 时按 `with_dialogue` 处理。

main 和 search 共用的片段混音会在带原声段的解说播放期间完全静音原片音轨，解说区间以外保留原剧对白；纯旁白段直接使用配音音轨。后期添加的背景音乐仍按任务配置混入。旧成片里的混音已经固化，需要从脚本规划、片段混音和拼接步骤重新生成，才能采用新的段落安排；只执行 `render_main.py` 不会改变段落类型。

`main_postprocess.json` 保存音频、识别、字幕修正的缓存记录，`final_subtitles_raw.srt/json` 保留原识别结果。源视频内容或速度改变时会使识别缓存失效。修改标题、字幕布局、弹幕样式或背景音乐只需重新渲染最后一步。手动修改 `final_subtitles.srt` 会保留；AI 修正失败后重试可复用已经完成的识别。

重渲染已有 main 项目（不会重新下载、配音或上传；缺少有效缓存时会执行识别/AI 修正）：

```powershell
.\.venv\Scripts\python.exe render_main.py --work "work\001_第28集"
```

UI 的文字布局区可分别设置标题、副标题和弹幕的顶部位置及字号，右侧实时预览，3 秒视频预览与正式成片共用渲染器。设置保存在 `overlay_layout`，整批复用；不改变整集母版，不重新识别字幕。示例文字仅用于预览，正式标题、副标题仍取任务列表内容。

支持 `--title` / `--subtitle` 覆盖标题，`--profile` 选择另一份文字布局配置；默认使用该剧最新保存的 UI 配置。支持 `--background-music` / `--no-background-music` / `--music-volume`。

旧项目已有最终加速时间轴的字幕，可明确选择直接使用本地字幕，全程不调用识别和 AI：

```powershell
.\.venv\Scripts\python.exe render_main.py --work "work\001_第28集" --use-existing-subtitles
```

旧项目缺少剧名元数据时还需提供 `--title "剧名"`。需要重做识别和 AI 修正时使用 `--refresh-subtitles`；它不能与 `--use-existing-subtitles` 同时使用。

使用本地素材配置（不下载、不上传）：

```powershell
.\.venv\Scripts\python.exe main.py --configure-only --edit-preprocess --preview-source "D:\path\episode.mp4"
```

可用 `--tasks` 指定另一份任务列表，`--profile` 指定配置文件路径。
